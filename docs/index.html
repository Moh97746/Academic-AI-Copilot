Core Tools

Three Tools. Zero Wasted Hours.

Each tool is battle-tested on real IEEE journal submissions and arXiv papers.

📄

pdf2md — PDF Extraction

Converts complex multi-column academic PDFs into clean, LLM-optimized Markdown. Preserves tables, equations, and hierarchical structure with zero hallucination. Feed your papers directly into Claude, GPT-4, or Gemini.

PyMuPDF4LLM
📝

word_formatter — Auto Typesetting

Programmatically generates perfectly formatted Word documents following strict IEEE and APA 7th edition standards. Handles OMML math equations, booktabs tables, and dynamic heading numbering automatically.

python-docx
🔬

SciWrite — Peer Review Agent

A 5-pass automated review pipeline: clutter extraction, voice vitality analysis, sentence architecture audit, keyword consistency check, and citation integrity validation. Catches issues before reviewers do.

NLP + Regex Engine

Quick Start

Up and Running in 30 Seconds

Clone, install, and start automating your research workflow.

terminal
# Clone the repository
$ git clone https://github.com/Marco9249/Academic-AI-Copilot.git
$ cd Academic-AI-Copilot

# Install dependencies
$ pip install -r requirements.txt

# Convert a paper for LLM analysis
$ python tools/pdf2md.py paper.pdf -o context.md

# Run the SciWrite peer-review audit
$ python tools/sciwrite_reviewer.py

# Generate a formatted IEEE Word document
$ python tools/word_formatter.py
